# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python program that provides three useful tools through a menu-driven interface.

### Tools Included

1. **Simple Calculator:** Performs addition, subtraction, multiplication, and division.
2. **To-Do List Manager:** Allows users to add, view, and remove tasks.
3. **Number Guessing Game:** Challenges users to guess a randomly selected number.

## How to Run the Program

1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code or a terminal.
4. Run the following command:

bash
python toolkit.py


On some Windows computers, you may need to use:

bash
py toolkit.py


5. Choose a tool from the menu and follow the instructions.
6. Choose option 4 to quit.

## Project Reflection

The hardest part of this project was organizing three different tools within one menu-driven program. The most challenging bug to fix was handling invalid user input without allowing the program to crash. I used try and except blocks to handle incorrect number inputs. I also learned how to use lists to store tasks and remove them when necessary. Writing separate functions for each tool made the program easier to understand and maintain. Testing each menu option helped me identify mistakes and improve the user experience. If I had one more week, I would add a feature that saves to-do tasks to a file so that they remain available after the program closes.
